# Window Cookie Store

This independent Window implementation uses each actual BrowserContext CookieJar, real CookieJar mutations, actual realm EventTarget/Event/Promise values, and Host-private records. `integration.patch` adds `src/cookie-store.js`, `src/cookie-jar-observer.js`, two focused tests, and only a Browser import/installer call. No Root production files or frozen Web Locks artifacts were edited by this task. It does not import or embed Native engine code.

The unmodified pinned `cookie_store.html` fixture improves from Root's actual `ok:false` to candidate `ok:true`; actual Native also reports `ok:true`. `evidence/*fixture*.json` retains raw harness outcomes and fixture/testing.js hashes. The Native binary digest in every oracle file is `9dec394124212f796724d4d32737ba66fdf0319ae6faaf8a1df8cccb4a70e23f`.

Behavior implemented and observed includes identity/prototypes/brands, conversion and Promise rejection precedence, genuine selected-method-realm query objects/arrays/Promises, default strict cookies and root paths, domain/path/URL scope, HttpOnly protection, expiry and maxAge, numeric expiry caps, named and nameless cookies, CookieChangeEvent construction/copying, and actual document.cookie/HTTP Set-Cookie changes. Per-cookie changes are queued trusted events with immutable mutation snapshots; same-value writes still emit a changed event, missing deletes do not. Listener presence is checked at mutation and delivery. Updating onchange retains its real listener slot. Native CDP bulk clear and natural expiry pruning are silent; those were explicitly calibrated and the candidate follows them.

Real same-origin borrowed methods use the method's document URL/realm and actual shared context jar. Actual cross-site child frames hide Strict/Lax, reject Strict/Lax writes and default deletion, and accept real SameSite=None writes/events. A retained removed frame continues reading and receiving real changes. Fresh Native retirement evidence also confirms queued events from both before and after removal survive. Real navigation abort detaches old subscriptions and pending tasks; candidate regression covers this. Exhaustive retained-old-realm operations across document replacement were not calibrated.

Native lazily creates CookieStore on first getter access. The candidate also uses a lazy Host factory. Persistent owner/controller/bridge/event records are genuine Host null-prototype allocations; no VM API table or private VM factory HomeObject is retained. VM helpers return only brand booleans, actual public snapshots, scalar fields or authored callback values. Actual public method/getter HomeObjects are their public prototypes. The global getter uses the existing native entry binding and successful private factory provenance for the actual owning Window implementation. Copied symbols and proxies do not authenticate CookieStore brands. The single focused real heap test preserves authored interface/factory-shaped lookalikes, ordinary objects, and genuine stores/events, and verifies zero actual stores before first getter.

The installed tough-cookie version has no `getCookies` secure-eligibility option: it derives Secure eligibility only from the protocol. A per-actual-jar read adapter therefore supplies a cookie-read context with `https:`/`wss:` only for observed trustworthy HTTP/WS loopback classes. Actual network/document URLs, stored cookie flags/domain/path and caller options remain unchanged. Fresh actual Native/candidate HTTP controls match for localhost, ::1, 127.0.0.1, 127.0.0.2 and 127.255.1.2. 0.0.0.0 remains insecure. Regression checks inspect real serialized storage, verify actual HTTP Cookie headers, enforce distinct host/path scope, and verify that caller `sameSiteContext:'none'` still excludes Strict cookies after eligibility adaptation. SameSite ancestry decisions use actual private document URLs before this adapter, including schemes. A full Native cross-scheme HTTPS ancestry differential was not run; no claim of complete Browser network SameSite policy is made. Subdomains of localhost are not included in the adapter without a fresh dynamic oracle.

Final validation ran serially in `/workspace/shared/window-cookie-store` with `--test-concurrency=1`: **17/17 on Node24.22.1,24.19.0 and26.13.0** (12 behavior cases,1 genuine heap/privacy case,4 existing cookie regressions). All270 observed source/test files stayed unchanged. `executed-graph.tar.gz` and `evidence/executed-source-hashes.json` capture that graph; dependencies and compiled bindings were shared with Root. Existing MaxListeners and VM Modules warnings are preserved. No broad/full/PureScript or broad heap suite ran.
