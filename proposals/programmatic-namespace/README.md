## Observed causes

Native creates real HTMLUnknownElement instances for null/empty/custom/Math/XML/XMLNS namespaces across active HTML, XML and inert HTML documents. Their actual attributes and CSS inline declaration exist even though their namespaces remain foreign. The earlier factory only selected this interface during an XML parse; programmatic calls and clone/import paths could allocate a generic Element without that real declaration. Focus on a normal HTML child then traversed such an ancestor and hit styles.js declaration(undefined). One canonical factory selection fixes the interface before allocation across all those paths; there is no wrapper/prototype repair or per-producer patch.

A distinct CSS defect remains even for an already correct HTMLAnchorElement or SVG element: Native permits an own authored style getter, but getComputedStyle never calls it. Candidate originally used that public getter for both declaration input and cache signature. Correcting only cascade input still called/propagated the getter through cache construction. Both actual private reads are necessary. The measured declaration remains live: real setAttribute and a held original CSSStyleDeclaration mutation update the computed color without calling the authored getter.
