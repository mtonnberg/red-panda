Frozen independent implementation, never applied to Root by this agent. Apply `core/core.patch` first. `cdp/cdp.patch` and `event/event.patch` each require core and can follow in either order. Exact base/leaf/patch hashes are in `manifest.json`; full current-Root snapshot and actual build artifacts are recorded in `evidence/`. No engine source was imported and no dependencies were added.

Core replaces jsdom's Proxy with real V8 ordinary objects carrying named and indexed interceptors. Real physical properties, symbols, inherited names, descriptors and preventExtensions behavior are handled by V8. Reserved virtual keys enumerate even when an inherited member hides their JS own descriptor. Genuine objects have private allocation brands; prototype/tag lookalikes do not acquire those brands. Their real CDP handle naturally has className Storage and no Proxy subtype. Actual V8 by-value serialization yields `{}` while authored JSON enumerates virtual keys. No protocol class/subtype substitutions were added.

The independent UTF-8 Wyhash/open-addressed area implementation reproduces table iteration through capacity growth, tombstones, deletion, reinsertion and retained-capacity clear. A 90-key holdout includes multibyte and long keys. Keys are normalized to well-formed strings. Both areas retain context/origin data, share the first-access actual wrapper within a live tree and get fresh wrappers on navigation. The 5 MiB quota counts UTF-8 values only and fails atomically. Captured DOMException factories allocate real VM errors. C++ passes its actual caller global to a private converter lookup, so cross-frame property writes/definitions and borrowed methods produce the measured caller/method realm errors. Node 24's explicit distinct-receiver guard is compiled out for Node 26's changed V8 callback API; actual inherited-write controls pass on both.

The CDP patch handles the general case where real own-key enumeration includes a key without a JS own descriptor. It emits the existing property record with absent value/accessors and false flags, matching actual Native entries. It has no Storage-specific branch.

StorageEvent ignores storageArea without Has/Get, including throwing getters, as measured. Its scalar slots and captured actual Event implementation remain Host-private. A real VM constructor receiver is initialized by EventIDL.setup on that same object. Reinitialization preserves composed/defaultPrevented/target, converts before a dispatch-time no-op and uses genuine Event dispatch. No automatic storage events are invented.

These are metadata calls, not heap walks. No broad, heap or PureScript suite was run.

Candidate frame access does not yet supply that broader facade. Storage getters were not selectively concealed to imitate it. HTTP same-origin frames genuinely share wrappers.
