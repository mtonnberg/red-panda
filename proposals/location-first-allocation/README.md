# Genuine first-allocation Location

The unchanged Native `window/location.html` passes, while the earlier candidate fails when it reads `Location.prototype.pathname.set`. This patch allocates the actual owned Location front in its originating VM at the canonical first factory allocation. It retains the existing LocationImpl, document, navigation hooks, generated exports object, wrapper cache and Window/document Location identity.

The public constructor, prototype, accessors and methods belong to the selected VM. Fronts initially have no own names or symbols. Prototype members and readonly URL components match the observed Native metadata. Private Host WeakMaps authorize actual fronts and retain the canonical backend association; copied implementation symbols and mutable backend wrapper pointers cannot grant authority. Utility worlds receive their genuine VM alias over the same backend. Ordinary unowned jsdom embedders retain the original factory.

Captured originating String, TypeError and Symbol-description getter perform conversion without consulting replacement public globals. Native primitive Symbols use their descriptions; an absent description becomes `undefined`. Boxed Symbols retain the actual originating String conversion error. No response, navigation success, native function source or upstream assertion result is synthesized.

`integration.patch` has seven leaves, listed with exact base and candidate hashes in `leaves.json`. `candidate/` contains the tested source, native artifacts/manifests, real matching CLI support, test and helpers. `evidence/base-owned/` retains the five original edited source leaves. The patch is dependent on the prior isolated history/JSURL/Location-boundary chain; it does not revert or reimplement that chain.

Root integration requires one context adaptation: when the heavy platform factory installer has moved into `dom-platform-factory-hooks.js`, apply the early Location import/install there, before `installDOMWrapperRealms`. Preserve the lightweight `platform-factory-hooks.js` facade and its lazy Worker imports. No dependencies or native build sources are changed by the integration patch.

Validation:

- The authored Native/candidate descriptor snapshot matches exactly for all 13 members, including initial zero own names, member order, function metadata and wrong-receiver errors. Raw records and report hashes are retained.
- The unchanged upstream Location fixture passes Native and candidate under its original 2,000 ms load and 2,000 ms assertion budgets, with exact registration map, testing.js, source fixture and binary identities. Native load/assert took 25/1 ms; candidate took 217/3 ms. All 7,740 inventoried inputs remained unchanged.
- All seven focused tests passed on Node 24.22.1, 24.19.0 and 26.13.0. Tests cover same backend and document identity, genuine originating allocation, brands, readonly components, utility aliases, original unowned embedding, actual owned frames, conversion and genuine backend URL arguments.
- The final allocation-only counterfactual uses a Host object with the identical public VM prototype. It fails the real V8 `sameRealm` check for the first front. Diagnostic prototype removal is restored immediately; production objects are allocated with their final prototype directly. The proper 6,818-input graph and counterfactual 166-input graph have separate complete unchanged before/after inventories.

The final validation controller returned outer timeout 124 at 15 seconds after all four child exit records, final inventories and status had been written. Child exits were 0/0/0 and the expected negative 1. This controller deadline is preserved separately in `evidence/final-outer-controller-status.json`; it is not reported as a clean controller exit.

Earlier evidence is retained: the original prototype/pathname gap, a mismatched newer CLI startup failure, the real `StringCtor is not a function` setter failure, the provisional incorrect Symbol expectation, the poisoned-global teardown crash and a separate eight-second Symbol-control controller timeout. Native's corrected primitive/boxed Symbol observations remain raw. The candidate observation for that eight-second epoch completed, but its final input guard did not; that epoch is not presented as a completed unchanged run.

CLI support is explicit: the first copied current launcher imported an absent quota export. Its bytes and failure remain archived. The successful standalone replay uses unmodified `8b10d2f:bin/red-panda.js`, whose corresponding cli-options bytes exactly match this isolated base. The launcher is reproduction support and is excluded from the seven-leaf integration patch.

Remaining bounds: this scope does not establish fresh cross-frame relative-navigation/incumbent behavior, every malformed URL/error string, constructor/expando descriptor parity, general WindowProxy reuse or cross-origin access authority. The new private URL-argument test intercepts the real backend only to inspect parsing and conversion; it does not assert a completed synthetic navigation. Source Location passed only on the prepared Node 24 runtime. Combined Root regressions, Worker lazy-install compatibility and additional upstream Location fixtures remain integration work. Native reference use is observational only; no target engine implementation is imported.
