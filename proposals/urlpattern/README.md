URLPattern isolated handoff

`implementation.patch` adds the independent URLPattern surface, compiler, generation/comparison methods, 17 focused tests, and narrow installation/clone handling in Window, worker, and utility contexts. The integration hunks were generated against Root's current CSS, Storage, and Canvas graph; they preserve those changes. `runtime.patch` separately adds the public V8 bounded-RegExp bridge. Production files were not edited by this proposal.

Apply both patches together, rebuild `native/build-runtime.mjs` with each exact supported Node executable, and restart browser/worker processes. The loader verifies full source/binary/Node/V8/ABI identities. Existing loaded bindings cannot acquire the new method through a source-only hot update. Exact successful build manifests are `build-runtime-*-final.json`; frozen source and patch hashes are in `frozen-manifest.json`.

Node's existing genuine URLPattern backend provides pattern parsing, syntax validation, and URL canonicalization. A fixed all-wildcard pattern normalizes actual input components. User-controlled pattern matching never calls the backend's unbounded `test`/`exec`: independent part compilation emits real V8 Unicode Sets expressions, and `RegExp::NewWithBacktrackLimit(..., 1000000)` performs every component match. The helper enters the actual selected-method VM using a genuine creation-context anchor, so captures and legacy RegExp state are real engine results. All retained backing records, parsed parts and backend objects remain Host objects. The authored instance has no implementation marker. Factory registration grants brands only to successful constructions; name registration classifies lookalikes without authenticating them.

Acceptance evidence:

- 1,017 retained raw Native controls: 263 primary; 54 extra; 10 group conversion; 263 ordinary matching; 150 opaque-path matching; 24 Unicode Sets; 6 prototype-setter; 2 matching RegExp-state; 5 construction RegExp-state; 240 generation controls. Actual worker/frame and utility-context controls are separately retained in `native-contexts.json`.
- All 17 focused tests pass on Node 24.19.0, 24.22.1 and 26.13.0, including the unchanged fixture, genuine clone failures, failed-transfer atomicity, ordinary lookalikes, real heap identities, Host-private records, poisoned intrinsics, foreign methods/results/errors, real HTTP workers and actual utility worlds. See `targeted-realm-status.json` and `tests-*-realm-final.txt`.
- Native and all three candidate runtimes pass the unchanged source fixture with the real native harness branch and nonzero observations enforced. `conformance-native-final.json` is Native; the final candidate realm-anchor reports are `conformance-*-realm-final.json`.
- Pathological matching is genuine bounded execution: Native and candidates match lengths through 18 and fail at 20 and beyond for `/((?:a+)+b|a+c)`. An owned subprocess shows the unmodified Node backend's length-40 matcher exceeds its 3-second diagnostic deadline (`node-match-bound.json`); the implementation does not use that path.

The initially failed candidate fixture caught Node's search-apostrophe normalization difference and is retained. Early simultaneous verification logs retain real VM deadline and synchronous-worker startup failures under CPU contention. Final bulk diagnostics use an explicit 15-second test-only VM budget; production evaluation and transport defaults are unchanged. The final checks ran sequentially.

Exploratory `controls.js` / `controls-groups.js` malformed-argument batches closed Native's CDP connection before a result artifact could be written. They are not acceptance evidence. The candidate rejects missing/nonobject `generate` groups with a realm TypeError; no claim is made to replicate a reference-process failure. `native-realm-controls.json` also retains the initial default-resource context attempt: its child frame was absent and data worker timed out. `context-probe.mjs` supersedes that context attempt with explicit iframe/worker resources and actual HTTP routes.

This is a bounded compatibility slice, not a claim that the entire independent browser or every URLPattern edge case is complete. No native target source, forked engine, new dependency, captured matching result, or fixture assertion replacement is included in the runtime implementation.
