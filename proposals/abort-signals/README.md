# Real Window AbortSignal proposal

This private overlay targets Root 8a8558d, copied with matching native addons to /tmp/red-panda-abort-8a8558d-ejhmlcnv. No production file is edited by this proposal. Apply integration.patch only after review; overlay/ contains the two new files. Existing Browser and Fetch integration hunks are deliberately small.

Keep the original jsdom AbortController/AbortSignal and its genuine realm EventTarget implementation. Abort callbacks now enter the existing real Window ErrorEvent reporter, allowing listener failure and dependent abort dispatch to finish without a process.nextTick exception. Static timeout uses real Window timers, safe-integer EnforceRange conversion, and bounded timer chunks; document/navigation/close disposal cancels pending jobs. Explicit post-load document.open retains timers/listeners in the same realm, as measured natively.

`installAbortSignals(page, window)` returns a private controller. `native(signal)` validates an actual jsdom signal from any Window, caches a private Node transport signal, and registers a genuine abort algorithm. Authored event stopImmediatePropagation or shadowed public properties cannot block cancellation. Timeout/default-reason messages match the native controls. `dispose()` clears timers and removes transport algorithms without intercepting process exceptions. No Node signal is returned by Request.signal.

Native Request observations matter: an absent signal is null; a supplied signal is exactly the original object, also for clone/copy; null/undefined overrides on a copied Request retain its existing signal. Fetch stores that object as publicSignal while raw.signal remains the private Node transport signal. Authored body producer identity and existing buffered/stream operations remain untouched; signal abort cancels the HTTP operation and response views, not the Request producer itself. Raw Node Request input from outside the authored realm is not a native-comparable public API and is not part of the native identity claim.

Native controls in native-control.json, native-contract-extra.json, native-lifecycle.json, and native-request-body.json are bounded public-API observations, with real socket cancellation and explicit cleanup. Candidate controls use identical expressions against the private overlay. The Request-body control also exposes a pre-existing separate native-vs-candidate locked-clone distinction; this proposal preserves existing lock validation and does not claim to fix it. Original fatal unchanged-fixture evidence remains under ../coverage48/abort-diagnostic/.

Limit: this change installs genuine Window/frame signals only. Worker global EventTarget/AbortSignal implementations are unchanged and are not covered by the Window error-delivery claim. Timeout suspension in an actual frozen/background browsing context is not modeled. Broader Request dictionary member ordering remains the existing adapter behavior, apart from correct signal-brand conversion.

Final validation: 117/117 combined tests; 37/37 focused Fetch/Request/Abort tests on each of Node 24.19.0, 24.22.1, and 26.13.0; the unchanged upstream AbortController fixture passes; all 13 scoped raw-CDP controls exactly match the retained native RemoteObject values. Final raw Request-body control retains the separate locked-clone gap. All owned jobs are quiesced. See report.json and matrix.json for exact source/test identities.
