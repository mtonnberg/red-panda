## Implemented slice

- Keep actual generated jsdom Storage proxies and their real implementation records; no wrapper-classification or protocol-result substitution. A private WeakMap authenticates public method receivers without reading authored metadata or symbols.
- Count 5,242,880 UTF-8 **value bytes** per area; exclude key bytes. ASCII, Latin, emoji, 1MiB keys, multi-entry quota, atomic failed replacement and reclamation are calibrated. Normalize lone surrogates as Native does. Throw the exact measured quota message; borrowed methods construct quota exceptions in the method's realm.
- Share backing maps by BrowserContext and actual private document origin. Persist both areas across navigation, other-origin visits/return and closing/recreating targets. New contexts are isolated. Independent opaque data documents have accessible distinct areas. Opaque entries use WeakMaps.
- Share the exact first-access generated wrapper, including its genuine original realm and prototype, across same-origin live frames. Full main navigation creates a fresh wrapper. Redirected frame origin updates cannot retarget an already published wrapper: the new origin receives another genuine generated wrapper. The redirect guard is a candidate regression invariant, not a claim of matching Native preload timing.
- Public method coercions reproduce measured Native Symbol descriptions, Symbol() -> "undefined", malformed surrogate replacement, required-argument errors and key() numeric conversion. Existing generated property machinery remains in place.
- No automatic storage events are synthesized. Native same-origin live-frame setItem controls recorded zero events.

## Remaining gaps; no full Storage parity claim

1. Native key() and own-key order follow its hash container; candidate preserves Map insertion order. Numeric index coercions match, but multi-key enumeration order does not.
2. Native reserved member keys appear in ownKeys/Object.keys while getOwnPropertyDescriptor may be absent. A standards Proxy cannot supply that exact combination. Native assignment to length is ignored; assignment to getItem can create a physical method shadow without changing the stored reserved value. The generated jsdom proxy still differs. Native own-property protocol enumeration also differs. No caller-dependent descriptor or fake wire response is used.
3. `native-wire.json` and `candidate-wire.json` directly show **both** Runtime.evaluate(returnByValue:true) results are `{}`. Authored JSON differs for reserved keys. Native Storage handles report className Storage; genuine candidate jsdom proxies report Proxy, and getProperties differs. These actual classifications remain intact.
4. Native data-page blank child frames had undefined localStorage/sessionStorage even after a100ms settle (`native-scope-v3/v4.json`); candidate inherits the opaque parent's accessible areas. This is an explicit broader opaque-frame initialization gap. Sandbox behavior, cross-origin access control, detach/retirement and full StorageEvent semantics need separate controls; this patch does not claim them.
5. Native disallows concurrent BrowserContexts and concurrent targets in one context. The first scope helper's attempted concurrent context operation is a retained setup failure (`native-scope.json`), not an isolation observation. Sequential disposal/new-context controls succeed.
6. Initial async frame probe incorrectly stringified a Promise before awaiting it (`native-initial.json`); its `{}` frame output is invalid instrumentation. v2 onward awaits correctly. Initial wire helper had a parse error before browser startup (`native-wire.txt`); corrected `native-wire-v2.txt` and `native-wire.json` are the actual wire control. Earlier failed tests and superseded results remain available as history, not passing evidence.
