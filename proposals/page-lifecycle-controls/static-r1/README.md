# Page lifecycle static implementation r1

UNRUN candidate, not an accepted functional handoff. Nine paths: six existing runtime files, one new Host-private transfer module, one new eight-case test file and one owned-child watchdog fixture. Base is exactRoot92908b9 plus Parent configuration/SID draft9af2aa84 (UNVALIDATED at preparation); no prerequisite changes are included in these patches. Its auth-before-ack branch and null-params handling remain intact.

Native-only observations are immutable in ../native-r1 (manifestd5ec544e...). Native12 are scenario observations, not twelve assertion passes. In particular Page.close's pending navigation command times out at the original2s limit while its target and transfers are actually retired. Owned NativeSIGKILL was finally cleanup.

Close acknowledges via a Host-private completion record before real Page.close ownership, then per-connection real session cleanup/Inspector+Target detach and actual targetDestroyed. Session disposal is idempotent. In-flight commands whose actual dispatched session was retired drop their otherwise late response. Existing direct Page.close backend and unrelated pages/contexts are preserved. Root-level context selection uses its existing actual loaded-context authority, preserving parallel-context ambiguity instead of inventing a target.

Stop reuses the captured actual Window/frame load cohorts and enters the cached captured VM invocation guard from CDP; authored window.stop replacement is not authority. A Host-private exact-navigation-signal record permits only the actual top-level main transfer to finish early. Reader cancellation retains received chunks and ordinary Buffer/Response/navigation decoding and parser creation, preserving real HTTP/cookies/history/load owners. Before headers it aborts the actual navigation with net::ERR_ABORTED without fabricating a Runtime exception. Generic Fetch readers and document parsing are unchanged. Navigation API stop can cancel its operation without aborting an early-finished transport that must commit normally.

The new eight cases cover Native close ordering/retirement/noPageenable, real pending-close HTTP and no-reply outcome, unrelated target lifetime, private stop authority/timers, pre-header cancellation/recovery, UTF8 chunk prefix through actual parser, real Fetch/XHR/defer/frame cancellation+load/timers/recovery, and an externally bounded owned-child authored infinite-abort callback with captured200ms VM policy followed by a real query/close. All are UNRUN. No full browser or complete lifecycle parity is claimed; redirect/cookie-await stop races, unknown schema variants, discovery-disabled close notifications and broader nested reentrancy need direct calibration before claims.

Private static apply-check/apply/reverse-check/reverse all succeeded with exactnine before/after bytes outside the Root Git repository. The rejected first static setup attempt is retained separately. Native/source/binary/dependency tests and functional acceptance are still pending. No Root source or native build was changed.
