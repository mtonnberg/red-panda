# HTML scalar reflection followup

This is an isolated independent implementation proposal, not a Root integration or a complete HTML-element parity claim. The tested scratch is `/workspace/shared/html-element-parity-20261031`, based on Root commit `9ab82e6`; `base-source.json` pins its original 407 source files. No Root runtime, dependency, native, or test file was changed by this proposal.

`integration-current.patch` contains one new Host-owned reflection module, main/utility installation calls, and eight focused tests. Its baseline is recorded in `integration-base-current.json`; it preserves Root's later request-metadata import. `integration-base-9ab82e6.patch` and `candidate/` retain the exact tested old-base leaves. The two patches express the same four-file change. Root still needs to validate the composed current graph.

## Implemented behavior

The module reads and writes actual canonical Element attributes. Captured generated `setAttributeNS` drives real custom-element reactions, MutationObserver records and retained Attr identity. Public accessors and conversion failures are genuine selected-VM values; private policy, implementation lookup and brands stay in Host records. Copied/inherited implementation-symbol lookalikes fail before authored conversion. Uninstalled, unowned jsdom is unchanged.

The bounded property set is `HTMLElement.tabIndex`, `HTMLOListElement.start/type`, `HTMLSourceElement.width/height`, `HTMLMarqueeElement.hspace/vspace/scrollAmount/scrollDelay/behavior/direction`, and `HTMLAreaElement.download/referrerPolicy`.

Raw integer attributes use measured ASCII-whitespace/decimal-prefix parsing and signed-32-bit bounds. Tab defaults apply only to HTML-namespace a/area/button/input/select/textarea/iframe; Native frame/object/summary return -1. Unsigned reflection uses nonnegative signed-31-bit getter bounds and per-property fallback. Ordinary numeric setters wrap through uint32/int32 before reflection. Contrary to normal WebIDL expectations, Native unsigned setters accept primitive BigInt after low-64-bit conversion only when the resulting value fits uint32; boxed/conversion-produced BigInt still throws. Signed setters reject BigInt. String setters use Native primitive-Symbol descriptions and retain raw enum attributes while getters canonicalize only measured ASCII keywords. OList.type defaults to `1` only when absent and preserves arbitrary present strings.
