## Generic float and protocol semantics

The f64 parser scans full decimal/hex/exponent/special-value grammar and underscore placement. It rejects whitespace/empty/partial tokens instead of accepting JS coercion. Only an accepted decimal token reaches the captured correctly rounded decimal-to-double primitive; that primitive does not decide acceptance. Hex conversion uses bounded exact BigInt guard/sticky-bit rounding, including overflow/subnormal/signed-zero behavior. No observed-input lookup table or permissive whole-token Number shortcut is used.

Actual Native controls cover decimal, signs, exponent, decimal/hex integers, hex fractions/binary exponents, minimum subnormal, overflow, case-insensitive short/long infinity/NaN, underscores, invalid underscore boundaries, empty/whitespace/bad text and malformed exponents. All fields validate before override commit. Null/missing coordinates clear the override; accuracy defaults0. Negative/out-of-range/nonfinite values accepted by Native are preserved. Wrong types and invalid tokens return the calibrated -31998 errors while retaining the prior actual position. Further exotic parser forms are not claimed exhaustively tested.

Dispatch recognizes exactly Browser.grantPermissions, Browser.setPermission, Browser.resetPermissions, Emulation.setGeolocationOverride and Emulation.clearGeolocationOverride. Omitted versus empty/null params are preserved and calibrated. Ignored origin/context filters still validate their types. Unrelated methods and the current configuration allowlists/session validation remain unchanged. Arbitrary permission names use a real private map; no canned permission-state list is substituted.
